## A Canadian application, with evidence at each boundary

Three owned Canadian Customer Edges discover the Canadian origin. A retained public allocation advertises the application on Toronto and Montreal Regional Edges. XC GeoIP authorizes the actual source address with `COUNTRY_CA`, default denial, and forwarding-header trust disabled.
