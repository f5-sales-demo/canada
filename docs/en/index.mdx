## What the tenant configures

<CardGrid>
  <Card title="Host the application in Canada">
    Place the origin in Canada. The tenant's origin pool discovers it through owned Canadian Customer Edges, so accepted requests reach the intended application backend.

    - [View the origin configuration](./use-case/#origin-pool--canadian-origin)
    - [Map the origin settings](./architecture/)
  </Card>
  <Card title="Serve through Canadian Regional Edges">
    Use the reserved public allocation to advertise the application from Toronto and Montreal Regional Edges. Check the allocation and serving edges to confirm where clients enter.

    - [View Regional Edge advertisement](./use-case/#load-balancer--regional-advertisement)
    - [Check Regional Edge placement](./verification/)
  </Card>
  <Card title="Control access by source country">
    Apply a service policy to the actual client source address. Permit sources classified as Canadian and deny other or unknown classifications. Client-supplied forwarding headers don't change the result.

    - [View the source-country policy](./use-case/#load-balancer--client-authorization)
    - [See the traffic checks](./presentation/)
  </Card>
</CardGrid>

These checks confirm the configured entry points, origin and source-country decision. They don't trace every packet between a client and Canada or identify the person behind a source IP address.
